# 电流采样与上位机验证（2026-10-08）

## 已验证的修正

1. 空闲态不再保持三相50%共模PWM，MOE关闭，OSSI/OSSR使六个输出为低。电流零点采集在关断栅极、等待INA240稳定后进行。
2. ADC1/ADC2在初始化中执行芯片自校准。每次独立转换先等待前次结束、设置通道并清除EOC/EOS/OVR，再触发并等待**新的EOS**。超时/溢出不再当作有效电流送入PI；锁存ADC故障并关闭驱动。
3. ADC1采样时间从25改为13个ADC时钟周期；TIM1更新向量直接清除UIF后启动采样，减少通用HAL分发延迟。保留三个独立单通道转换。
4. 电流环输入使用三点中值和EMA（alpha=0.5）。40kHz下低通-3dB约4.60kHz，二者合计低频延迟约50μs。单周期冲击被中值抑制，持续阶跃从第二点开始通过，不设置人为电流幅度钳位，也不强制三相和为0。
5. **每个原始样本仍用于过流检测**，滤波不改变原始约20A/连续5个采样的过流逻辑。电感100μs脉冲测量使用原始电流，避免低通延迟直接改变di/dt。
6. 新增0x06原始电流帧：`u16 seq; 3*u16 ADC; 3*f32 A; u16 flags`，22字节。标志仅表示原始值与中值相差超过2A，属于诊断计数，不能解释成确认的物理故障。36字节常规遥测现在显示处理后的输入，mA整数饱和而不回绕。
7. 遥测CRC编码移至主循环，ISR只准备数据。消除参数回复与ISR同时写TX环头的竞态，并减少控制中断耗时。

ADC内核最终由生成的RCC代码分频为36MHz，不能仅看到144MHz源就认定ADC过频。INA240A2本身具有PWM共模抑制，但仍应避开开关边沿采样；这是模拟瞬态机制的判断，不等于已用示波器确认了板上噪声来源。参考：[ST数据手册](https://www.st.com/resource/en/datasheet/stm32c562ve.pdf)、[TI INA240数据手册](https://www.ti.com/lit/ds/symlink/ina240.pdf)。

## 实际上位机与换相回归

`gui_workflow_probe.py`通过真实串口驱动GUI按钮和异步逻辑：同步参数、设置1A限流/标定电流、执行完整标定、显示35%阶段进度、回读后弹窗、停止断开。总2807帧、丢帧0。自动得到21极对、方向+1、偏置0.298639rad、一致性0.992422。结束IDLE、fault=0。

R=1.3555Ω、L=141.0μH仍为含逆变器误差的估算值，没有用参考200mΩ覆盖，也没有据此自动修改PI。已验证短时±0.3A/±0.6A闭环双向响应，速度样本分别达到+3.80/-6.47rad/s，结束IDLE。记录：`gui_workflow_result.json`、`commutation_results/20261008_221946_torque.json`。

14项GUI/协议工作流回归通过；固件GCC编译通过。未验证满载/高速下的采样窗口与新滤波稳定性；速度/位置整定、准确R/L、Flash持久化不在本次完成范围。ADC自校准后母线显示约23.08V；仍需万用表核对当前母线及VDDA后才能判断比例精度，不盲目补偿。

## 额外40kHz短记录

源码另有按需尖峰捕捉器，GET/SET 0x061D控制状态，GET 0x061E/0x061F读取触发/环索引。记录64周期，触发后16周期冻结，常态不写缓冲区。已实测触发冻结，12秒i/f测试没有故障：原始Iq标准差0.125A，处理后0.059A，平均处理后Iq约0.602A；见`current_noise_results/20261008_223801_traced_if.json`。DAP读取的状态与串口结果不一致，因此不能以该DAP读数作为有效捕捉记录。

最后增加USB下载路径：GET 0x0700..0x073F，设备回复0x07帧，载荷`u16 index + 8*u16 metadata + 3*f32 current`，30字节。用户重插USB后已完整下载64条记录（`current_noise_results/20261008_230008_reconnected_trace_if.json`）。触发点A相原始电流-6.72A，但中值/EMA后-0.41A；前后三个周期恢复正常。正常ISR起点TIM_CNT约1720、向下计数，ADC读取结束约1090，最小CCR约867；尖峰周期延迟到CNT984才开始，结束349，采样跨越PWM比较边沿。该记录支持“软件触发受ISR延迟影响，采样落入开关边沿”的判断。

因此进一步改用TIM1更新TRGO触发ADC1三通道注入序列，JDR1/2/3保存同周期结果，ISR只读取已由硬件触发的扫描；保留原始过流保护与中值/EMA。GET0x0620=1表示新路径。新路径已编译、烧录并实测：同条件10秒0.6A/1Hz i/f原始>6.45A次数14→0、原始峰值14.02→2.77A、平均处理后Iq0.5975A、ADC超时0。小幅纹波没有进一步降低，处理后Iq标准差0.0616→0.0743A，C相有约+0.13A均值残差。完整结果及剩余限制见[驱动测试报告](DRIVE_FULL_TEST_REPORT.md)、[实测曲线](test_visualizations/20261008/README.md)。

无线探针曾在2MHz等频率出现“Timeout reading from probe”，不能简单认定为电机板断电。使用`-M under-reset`、1MHz完成烧录约8.2秒。烧录脚本现保留错误输出，以1MHz开始、硬件复位并检查USB枚举，避免无依据的超低频长重试；USB枚举只确认设备出现，不等于串口协议已健康。
