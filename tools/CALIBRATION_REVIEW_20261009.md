# CrowerFOC 校准流程审查与 ODrive / VESC 对比

审查日期：2026-10-09。仅检查本地源码、已有实测记录和官方资料；没有连接探针、操作串口、烧录或驱动电机。本文提出改进设计，尚未修改运行固件。

版本说明：本审查记录的是改动前的27秒/0.5A流程。之后用户授权固定较大校准电流，离线源码已更新；具体见[固定5A校准更新](CALIBRATION_UPDATE_20261009.md)。新固件尚未烧录验证，设备历史测试仍对应旧版本。

结论：现有编码器换相标定已经具备正确的正 Id 对齐、极对数/方向自动测量、正反向圆周平均，但 R/L 仍是未经充分校验的估算，整个流程还不构成可以自动整定、掉电复用和验收的完整校准系统。优先修复有效性管理、电压误差与脉冲时序，随后再做全周角度误差和电流环性能验证。

## 1. 当前真实流程

源码：[phase_test.c](../Software/MotorTest_cmake/phase_test.c)，主流程行 874–1008；ADC 零点行 1210–1223；GUI 结果行 749–775、进度行 837–868。

| 结果 | 提交 pp/dir/offset，置单一 calibrated 标志，回 IDLE | R/L 在前面已直接改入配置；无独立有效标志；无 Flash；无电流闭环定量验收 |

## 2. 官方方案中可借鉴的部分

对比时区分版本：ODrive 0.6.12 在线文档与公开 ODrive 仓库中的旧产品固件不是同一套当前商业固件。下面只引用各自明确可见的行为，不将公开实现等同于所有 ODrive 产品。VESC 引用审查当日官方仓库 master，后续可能改变。

| 项目 | ODrive / VESC 已公开行为 | 对 CrowerFOC 的意义 |
| --- | --- | --- |
| R | ODrive 将测试电流与最大校准电压分开配置，检测失败与相间不平衡；VESC 缓升电流、取多样本，综合检测按功耗预算选择测试电流 | 电流、输出电压、耗时、温升预算都要受约束；不能只求一次 V/I |
| L | ODrive 用正负交替电压及多次电流变化；VESC 当前实现使用 HFI 多方向数据、重复平均和采样模式管理 | 使用重复、同步、双极性激励，给出统计可信度；并不要求本项目直接移植整个 HFI |
| 编码器 | 公开 ODrive 扫描方向/响应并检查配置 pp 与 CPR 是否匹配，再正反扫描；VESC 自动检测比值/方向并正反多点平均偏置 | 当前正 Id 方法正确；应补足拟合、重复性与机械角覆盖 |
| 电流 PI | 两者公开实现均根据 R、L 与带宽/时间常数计算 PI 参数 | 前提是参数可信，还要考虑本项目的采样、滤波、计算和 PWM 延迟 |
| 使用与保存 | ODrive 分开记录电机参数与换相有效性，支持配置保存；绝对编码器在装配关系不变时可复用偏置 | 用户仍可一键完整标定，但固件内部需要独立结果与有效性，开机自检后复用 |

对应官方依据：[ODrive 电机参数文档](https://docs.odriverobotics.com/v/latest/articles/motor-parameters.html)、[ODrive 公开 motor.cpp](https://github.com/odriverobotics/ODrive/blob/master/Firmware/MotorControl/motor.cpp)、[ODrive 公开 encoder.cpp](https://github.com/odriverobotics/ODrive/blob/master/Firmware/MotorControl/encoder.cpp)、[VESC mcpwm_foc.c](https://github.com/vedderb/bldc/blob/master/motor/mcpwm_foc.c)、[VESC conf_general.c](https://github.com/vedderb/bldc/blob/master/conf_general.c)、[ODrive 编码器文档](https://docs.odriverobotics.com/v/latest/encoders.html)。

成熟实现也有平台专用假设。例如 VESC 当前 L 测量包含用于其控制方案的缩放，不应把这种系数直接搬入本项目；也不能照搬其他硬件的增益、采样频率、绕组归一化或大电流设置。

## 3. R 偏大的原因与改进

代码确认：当前 Vd 是 PI 输出在电压幅值限制之后、最终 PWM 占空比限制之前的指令，没有测量绕组电压。它包含为了克服死区、器件及连接损耗而额外需要的指令电压。

在现有 40 kHz、144 MHz DTS、deadtime=0x50 条件下，配置死区约 0.556 µs；23.109 V 母线的 `Vbus × deadtime × fPWM` 量级约 0.514 V。理想三相符号模型下，当前 A 正/B、C 负的 d 轴损失量级可到约 0.685 V。R=1.309 Ω 在 0.5 A 时对应约 0.655 V 指令电压。因此，死区误差与观测值处于同一量级，是值得优先验证的解释。**这只是由配置推导的量级分析，不是实测死区补偿量，更不能直接从读数减去这个值。** 驱动器内部延迟、实际开关波形、电流符号及器件压降仍需验证。

建议在用户配置的电流、功耗和电压范围内逐步选取若干电流水平，同一方向拟合：

`Vcommand ≈ R_effective × I + Verror(direction, angle)`

拟合斜率比单点 V/I 更能区分固定压降；正反方向分别拟合，检查斜率与截距。仅使用正负同幅值点作 ΔV/ΔI，不能消除随电流符号翻转的死区项。扫描多个定向电流矢量检查通道/绕组不平衡，保留实际 Id/Iq、原始三相电流、母线、最终 duty 和稳定窗口数据。器件导通电阻等随电流变化的损耗仍会进入斜率，不能保证得到纯绕组电阻。

R 测量需要：缓升电流；限制输出电压；以误差、斜率、方差及轴是否静止判断收敛；限定单段和总超时；无足够信噪比则报告“不足以辨识”，而不是自动加到较大电流。

200 mΩ 两相四线测量只用于独立核验，不写入默认参数。应先确认接法和测量端点：星形每相通常为两相间的一半；三角形物理支路与控制等效相参数需要明确区分。当前幅值不变 Clarke/Park 与 SPWM 的物理电压/电流口径应先统一，不能盲目添加 3/2 或 2/3 系数。

## 4. L 脉冲时序及辨识

代码事实：ADC 在 ISR 入口取样；t=4000 先保存零电流样本，再设置 1 V duty；CCR 在 ISR 末尾写入，而 compare preload 已开启，所以新 duty 要到下一个更新才生效。t=4004 的样本已经用于计算，算法却用 4×25 µs。

理想同步模型下：写指令到起始输出延迟一个周期，取样终点之前只有约 3×25=75 µs 激励。用 100 µs 分母会使 L 偏大，理想误差约 4/3。实际采样孔径、中心对齐 PWM 波形及模拟响应会进一步影响结果。**确认了指令/生效时序未对齐；实际有效电压积分需波形验证，不能直接把历史 L 统一乘 0.75。**

即使修正时序，单次原始端点也容易受量化、纹波影响。0.5 A 在当前标度下只有约 15.5 ADC 计数；短脉冲末值约为数十计数的数量级。已有 L 结果也存在明显散布，尚不能确认真实电感或磁饱和。

建议：记录每次实际生效 PWM 周期及原始 ADC 时间；重复正负脉冲并拟合多个点，限制每个脉冲电流和伏秒；用有效电压模型处理死区，并纳入 `V = R·I + L·dI/dt`。放电必须判断实际残余电流，而不只等待固定时间。正负重复结果应有离散度与一致性门槛。快速瞬态辨识使用同步原始样本和重复统计，不能使用有约 50 µs 延迟的当前中值+EMA 输出代替瞬态。

首先得到可信方向等效 L；在编码器换相有效后，再测多个角度或 Ld/Lq。当前测量不足以声称已辨识 Ld、Lq。

## 5. 编码器的进一步验证

保留当前正 Id 对齐与正反向平均。极对数由数据辨识，21 仅作为外部参考。新增浮点 pp、最近整数残差、分段角度回归、正反方向重复以及失步检查。高集中度不能独立保证 pp 正确或固定偏置准确。

当前偏置动态扫描每方向 2 电周，在 pp=21 时仅约 34.3°机械角；忽略首秒后每方向有效扫描约 25.7°。这不足以描述全机械周的磁铁偏心、编码器非线性、齿槽和装配误差。首次自由轴完整标定应覆盖完整机械周，保存“命令电角度与编码器映射”的分箱残差曲线，报告偏置重复性、角度 RMS、P95、最大误差和正反差。

现有 quality 是单位误差向量平均的模。0.98778969 若误差近似零均值集中分布，对应圆周标准差约 9.0°电角度；当前 0.95 门槛约 18.4°。这不是编码器本体精度，含负载角、齿槽、噪声与时延，也不是“98.8%精度”。均值误差与正反差允许 1 rad（57.3°电角度），应根据电流/转矩验收要求缩紧并记录实际值。

磁铁偏心的补偿 LUT 可在确认全周可重复非线性之后考虑；正反平均只会抵消近似对称的摩擦/动态滞后，不保证抵消外部固定负载。电角度零点和关节机械零点应分别保存。

## 6. 结果有效性、控制验收和上位机

优先级 P0：

- R/L 测量失败应结束相应阶段并报告明确原因；采用候选结果，避免中途直接覆盖运行配置。单独维护 current-zero、R、L、commutation、controller-validation 有效状态及失败原因。
- 完整成功应明确需要哪些子结果；允许显示“换相完成，但 R/L 不可用”，而不能统一称参数已完成。当前 GUI 虽注明 R/L 为估算，但成功标题仍会造成混淆。
- 当前设备闭环仅检查 pp 非零，GUI 也只检查 mapped pp；更改 dir/offset 会清 calibrated，但仍可进入闭环。正常控制应要求经过验证的完整换相配置。手动配置若保留，应独立验证后生效；不能仅填 pp 就视为可运行。
- 增加标定专用的电压、脉冲电流、位移/速度、耗时和能量预算，全部由固件执行；保留现有原始过流、ADC/编码器故障及主机心跳中断停止。

优先级 P1：

- 修复 L 的生效时序，再实现重复辨识；实现 R 多点/多方向拟合；每次标定前使用与运行相同的注入采样路径检查零点与噪声。增益校准需要外部已知电流，不能只凭软件零点自动得出。
- 经 R/L 校验后，按 `Kp=L·ωc，Ki=R·ωc` 给出保守 PI 候选，ωc 单位 rad/s；带宽受采样/滤波/计算/PWM总延迟约束。通过限流内的小阶跃验证上升时间、超调、稳态误差、Id/Iq串扰和饱和恢复，再应用。
- 先修复电流积分器抗饱和，以及 SPWM 可用电压与圆形限制不一致：目前 vmax=0.577Vbus，但不带共模注入的 duty 边界保证各相线性电压仅约 0.478Vbus。它通常不是低电压 R 测量偏大的主因，却影响高指令验证和实际电压重建。
- 多轮全周换相验证；保存阶段原始数据及诊断曲线。速度环另用限流条件下的速度阶跃、双向低速、稳态误差、扰动和带载测试整定；R/L与编码器标定不能代表速度环已经自动整定。

优先级 P2：

- Flash 版本、CRC、提交标志和掉电恢复；保存装配相关 offset、方向、pp、参数及各自有效性。启动检查传感器、供电、零点，配置有效时复用，不自动进入闭环。温漂、电机/相线/磁铁变更应使对应项目失效。
- 扭矩常数/磁链及实际 Nm 核验单列。持续扭矩验收还需真实负载、温度记录、热保护与铜耗口径验证；不能由一次校准结果替代。

用户操作保持一个“完整标定”入口。内部建议顺序：预检/同路径零点 → R 多点辨识 → L 同步重复辨识 → PI 候选验证 → pp/dir → 全周偏置/映射验证 → 可选闭环小幅验证 → 结果分项提交/保存。每阶段使用设备返回进度、真实采样数量和结果状态；取消或失败统一关断输出，停在空闲。位置受限的已安装关节应只执行可行的子项，不允许把自由轴全周扫描作为默认开机行为。

建议结果弹窗同时显示：通过/未通过项目、测量条件、有效性、R拟合曲线与误差、L重复分布、pp拟合残差、全周角度误差、电流阶跃指标、是否已保存。成功条件来自设备校验，不能仅由 27.1 s 计时决定。

## 7. 下次上电后的验证次序

1. 验证运行路径零点、已知电流增益与三相残差，不用更强滤波掩盖系统偏差。
2. 同步观测 PWM、实际相间电压与 ADC 采样标记，确认死区和 L 激励时间；若没有相电压测量条件，明确保留有效电压模型的不确定性。
3. 在用户确认的电流/热预算内完成 R/L 重复检测，与四线法及独立电感测量比较。参数和电流选择不写死为本电机特例。
4. 做多起始角、多轮正反换相和全机械周残差，再以新配置完成电流闭环定量验收。
5. 完成限流、速度和热监测后，再开始已准备的持续 Iq/扭矩试验。此次审查没有执行这些硬件步骤。
