# 初轮Iq持续保持试验

当前只准备试验工具，尚未实施持久试验。电机是否上电、加载方式、目标与温度观测等待用户确认。

现有40kHz电流环能在已测小电流范围跟踪指令，1kHz速度环能双向转动；没有完成带载持续运行、温升、阶跃带宽和饱和恢复验收。电流环的电压饱和抗积分饱和与SPWM限幅仍需完善，速度估计及低速性能仍有不足。

## 能测什么

没有标定转矩常数，也没有接入转矩传感器。当前工具测的是**编码器闭环下的Iq保持能力**，不是Nm精度或额定持续扭矩。固定轴的试验是堵转电流保持；带可控负载并测转矩才可以进一步评估实际输出扭矩。

空载轴不能直接持续施加恒定Iq：会加速。当前速度参数仅限制速度模式的目标，在Iq模式下没有实际轴速限制。该工具只接受明确的`locked`或`loaded`试验配置，不提供自由轴恒定Iq模式。

## 前置条件

1. 电机及功率板供电正常；当前试验母线范围沿用此前验证的16~26V。
2. MCU复位/掉电后换相配置会丢失。先在轴可自由转动时执行完整标定，再关闭输出、固定/加载，保持MCU供电。
3. 工具会读取当前pp、方向、偏置、一致性与标定标志，不写死pp=21，不自动加载历史值，也不会对固定轴执行旋转标定。
4. 确认加载机构能可靠承受作用力，明确允许轴速、相对位移与时长。手扶轴不作为固定装置。
5. 当前固件未提供有效温度遥测与自动热停机。工具初轮范围限制为不超过1A、60秒，不能据此开展无人看守或高电流长时间试验。

## 准备好的工具

`torque_endurance_probe.py`显示进度、支持立即停止；先检查设备与换相配置，设置并回读试验限流，进入零目标Iq闭环，用0.5秒渐升至目标，保持指定时长，最后停机清零并回读空闲。

原始与处理后电流按同帧序号保存，每个遥测帧都记录；不沿用空闲时历史Id/Iq做统计。记录轴角、相对位移、速度、母线、占空比、故障及40kHz尖峰/超时计数。结果保存为JSON、CSV、PNG、SVG。GUI停止、故障、失联、速度/位移超限、明显电流异常都终止试验；固件750ms心跳停机仍生效。主机停止阈值不等于已经具备独立硬件安全保护。

示例仅供加载条件确认后使用，**不是已经执行的试验**：

```powershell
HostUI/.venv/Scripts/python.exe tools/torque_endurance_probe.py --load locked --iq 0.3 --seconds 30 --max-speed 1.5 --max-travel 0.1
```

`--max-speed`为主机实测轴速阈值，轻微超限连续50ms停止，超过2倍立即停止；另有轴位移限制，避免固定装置松动时只依赖噪声较大的速度差分。参数需匹配实际机构，不把示例值当作电机额定能力。

平均Iq跟踪暂用误差不超过max(0.05A,目标的10%)作为初轮功能判据；报告同时保留标准差、95%误差、前后漂移、Id误差、三相RMS和占空比触边比例。该判据不认证精密扭矩控制，也不认证热稳定。
