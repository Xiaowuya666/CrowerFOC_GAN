# CrowerFOC 与 ODrive 功能对照（2026-10-09）

> 状态表为较早的只读快照，以下“未实现”判断已被后续工程更新覆盖。请先看 [2026-10-09 核心实现与实测状态](ODRIVE_CORE_IMPLEMENTATION_20261009.md)，其中包含当前控制/位置/Flash/CAN能力、SPWM/SVPWM变更、RPM范围、弱磁判定和验收限制。本文后续表格保留为各产品型号的差距分析，不代表当前工作树状态。

基线为查阅当日 ODrive 官方 current-generation 文档0.6.12，覆盖Pro/S1/Micro的主要功能类别和型号扩展；不是逐个复制数千个API字段。型号专属和实验功能分别说明，不把枚举项等同于可用实现。本项目结论来自当前应用源码、GUI及已有实机报告；未重新启动电机。

总体判断：已有单轴FOC、编码器换相、电流/速度闭环、完整校准、USB调试和若干软件保护；尚缺完整位置伺服、运动指令规划、持久化、功率/温度管理与机器人通信。低电流空载测试通过，不等于ODrive等级的功率/负载验证。

状态含义：基本实现=在现有低电流范围运行通过；部分实现=有实际代码但能力/精度/覆盖不足；未实现=当前应用未接入，协议枚举/外设初始化不算完成；未验证=需要硬件或负载实验。

**型号专属硬件与不应误计的功能。** [官方型号对比](https://docs.odriverobotics.com/v/latest/hardware/odrive-comparison.html)区分Pro/S1/Micro。

- 当前一轴与新ODrive一轴一致，不是缺少功能。旧v3.6双轴不是这个关节驱动必须复制的设计。
- 隔离GPIO、差分/过滤编码器接口、隔离CAN、风扇等按型号存在。当前项目未完成相应产品等级的硬件设计审核和验证；是否添加要按实际布线/环境/散热需求决定。
- 制动电阻不是所有ODrive都内置支持；再生能量处理则需要根据所用电源和机构落实。
- ODrive API中的MIX_CHANNELS官方标为未实现；MIRROR标为Pro/S1不支持，不能把它们当新ODrive通用成熟功能来算本项目差距。
- 抗齿槽、无感、谐波校准、主动功率限幅或CAN升级中的实验标签需保留，不能当作全工况成熟保证。
- MIT式阻抗控制、S曲线、功能安全认证、所有型号的反接保护不是本次已核实的ODrive通用标配，若作为关节需求提出应另立需求，不混入“缺少ODrive功能”的判断。

建议顺序：先补温度与母线/再生/驱动故障保护、持久化和真实功率测试条件；再完成Nm模型、指令变化率/速度裕量控制、L精度与全调制采样验证；随后实现位置控制、关节坐标/限位和轨迹，再接CAN；抗齿槽、谐波补偿、双编码器和弱磁按实测需求安排。持续扭矩试验优先需要温度、电流定额、加载和再生边界，不能仅靠把限流数字改到20/40A。

本项目证据入口：[当前实机调查](CURRENT_LOOP_ROOT_CAUSE_20261009.md)、`Software/MotorTest_cmake/phase_test.c`、`foc_limits.h`、`crowerfoc_proto.h`、`generated/hal/mx_fdcan1.c`，以及`HostUI/crowerfoc_protocol.py`。本次只新增对照文档，未改变运行参数。
