# CrowerFOC 快速使用指南

这份指南用于日常连接、标定和低风险试运行。上位机界面单位为 **rpm、°、A、V**。本项目仍在台架验证阶段；软件限流不代表硬件连续额定能力。初测应空载、机械可自由转动，并设置较低的电源限流和软件运行限流。

## 连接与启动

1. 接通电机板控制 USB。Windows 通常会出现 `0483:5710` 的 USB 虚拟串口；端口号会变化，当前记录中是 COM7。
2. 双击 `HostUI\run_gui.bat`。连接后等状态、参数和曲线开始刷新。连接本身不会使能电机。
3. 连接失败时先关闭串口监视器和其他上位机，再重试。设备管理器能看到 COM 口只表示 USB 已枚举；如果提示“拒绝访问”，通常是端口正被别的程序打开。

烧录用的是另一条 USB：Horco CMSIS-DAP v2（VID/PID `FAED:4870`）。本次已由 pyOCD 检出并成功烧录；COM9 是探针的复合串口，不是电机板控制口。不要把 COM9 当成电机板串口。

## 标定与运行

1. 确认机械机构没有接触限位，轴可以自由转动；移走轴上的工具和松散线缆。给电机板供电并确认母线读数合理。
2. 在空闲状态设置“运行电流限制”和“速度指令限制”，点击应用并确认回读。电流上限可配置到 40A，但这不代表当前板卡、散热和接线已完成 40A 连续能力验证；首次运行请使用低电流。
3. 点击“完整标定”。当前固件标定使用固定 5A 档位，可能使电机短时动作；保持空载并随时准备按停止。完成后核对极对数、方向、偏置和 R/L 结果。R/L 是逆变器与电机的在线估算值，不应直接当作精密测量值。
4. 选择力矩、电流或速度控制模式。力矩滑块松开会回零；输入框模式需显式发送。位置模式使用角度，目标只从当前位置附近的小步长开始。
5. 输出轴第二编码器目前尚未安装/连接，保持禁用。固件会因此拒绝依赖输出轴反馈的速度与位置闭环；不要通过填写固定减速比绕过。安装并验证第二编码器后，再检查角度连续、方向和实际减速比。
6. 停止时点击“停止 / 空闲”，确认状态回到空闲且目标为零。故障排除后再手动清故障；清故障不会自动重新使能。

## 状态、保存和安全提示

- 灰色表示空闲；橙色表示标定；绿色表示闭环运行；红色表示故障。失联时控制区禁用，重新连接不会恢复旧指令。
- 驱动期间主机必须持续发送心跳；上位机断开后，固件会在约 750ms 内关断输出并锁存通信故障。
- “保存参数”只保存设备确认过的配置；运行目标不会在重启后恢复。保存后可通过受控重启和回读验证。
- 温度保护有可配置开关。TEMP2 已按独立温度计提供的两点拟合为 PTC 线性曲线：25℃/620Ω、48℃/848Ω，斜率约 9.913Ω/℃；TEMP2 接口电路为 10kΩ 上拉至 3.3V、传感器接地。该直线在 25–48℃之间有实测锚点，范围外是外推，传感器具体型号和高温曲线仍未确认。保护默认关闭；需要启用时先在“参数与配置”核对 TEMP2 读数及降额/跳闸阈值。母线过压设置及器件额定值应在每次更换电源前核对。
- 当前 PWM/电流环中断为 25kHz；常规 USB 遥测默认约 100Hz，屏幕绘图刷新率不是采样率。曲线仅显示内存滚动窗口，不提供记录器功能。
- “故障与自检”页提供故障状态与器件排查清单；“CAN调试”页支持项目自定义电流语义帧的离线编解码和设备 CAN 计数读取。没有 CAN 适配器时不能完成真实总线验收。
- 电流环扫频是独立操作，d 轴注入，100–4000Hz、16个频点；扫频点的激励幅度、饱和率或增益不满足判据时会标为无效。最近实测在 1.25–1.8kHz 出现无效点和增益峰，实测 −3dB 带宽未能确定；界面上的“1kHz目标通过”不等同于完整带宽/稳定裕度验收。查看 [本次扫频记录](validation/current_loop_sweep_2026-10-14.png)。阶跃带宽分析已移除。
- 固件不再按实测转速跳闸；速度模式仍受“速度指令限制”约束，力矩模式按电流限制运行。运行电流、母线电压、编码器、驱动故障和通信看门狗保护仍有效。避免在机构超出机械额定转速时运行。
- CAN 适配器尚未用于真实总线验收；第二编码器功能需在传感器安装接线后验证。此前测试数据仅适用于记录时的固件与硬件状态。
- 2026-10-14 扫频截图显示 100–1000Hz 点被标为有效，1.25/1.5/1.8kHz 点被标为无效，1kHz附近增益约 +1dB、相位滞后约45°；无效点原因需结合表格中的注入电流和饱和率确认。不得把这次结果解释为“已验证 1kHz 带宽”。

详细连接检查、命令、测试边界和故障处理见 [在线测试与调试手册](CrowerFOC_在线测试与调试手册.md)。
