# CrowerFOC 编码器换相诊断与修复（2026-10-08）

最终固件已通过 Horco CMSIS-DAP（846703532218、2 MHz SWD）烧录，并通过 COM7（0483:5710）验证。编码器闭环正、反方向均产生转矩；调试结束时已回到 IDLE、设定值归零、i/f 关闭、故障为零。这里只验证低电流短脉冲换相，没有完成高转速、满载或速度/位置环整定。

## 已确认的根因

原偏置标定调用 `ph_foc_run(s_if_ang, 0, 2, ...)`，随后计算 `offset = s_if_ang - dir * pp * mech`。但该电流矢量的实际空间方向是 `s_if_ang + π/2`。低速同步时，转子 d 轴接近电流矢量方向，因此原标定得到的是约 `真实offset - π/2`，还叠加摩擦/负载角误差。

闭环随后使用 `theta_est = theta_rotor - π/2`；给定正 Iq 后，实际电流空间角为 `theta_est + π/2 = theta_rotor`，主要变成真实 d 轴电流。因此“计算坐标系里的 Iq 跟踪正常”不能证明真实转子 q 轴电流正确，也不能证明有转矩。

修复用正 Id、Iq=0 的旋转磁场测量；静止 Id 对齐只作为偏置初值，再通过正/反向扫描的等权圆周平均抵消摩擦和齿槽停位偏差。只有两方向一致性检查通过才提交映射。没有写死21或实测电阻；上电极对数为未知，未配置的编码器闭环会被拒绝。

## 修改内容

- `Software/MotorTest_cmake/phase_test.c`：正 Id 标定、16圈电角度自动测 pp/方向、静态初值和正反向均值、候选映射通过后提交；负角度先归一化再查正弦表。
- 编码器读取从每50次主循环改为500μs时间调度（实际频率受主循环负载影响）；与ISR共享的机械角/位置/速度改为 volatile。有效数据超过5ms则停止编码器闭环/标定。
- SSC数据与安全字连续接收；新增CRC-8/J1850（poly=0x1D、init=0xFF、xorout=0xFF），并检查安全字系统/接口/角度有效位。实测读取失败计数为0。
- 遥测电角度现在表示实际传给Park的角度，i/f及标定时也可观测；新增只读参数0x0203~0x020A。空闲时该遥测角度和Id/Iq是最后一次驱动计算值，不代表仍在输出电流。
- 原电感阶段的1V电压阶跃持续100ms，绕过电流环限流，曾实测超过3A。现先卸流100ms，再施加100μs脉冲。R/L数值仍不作为准确电机参数，也未根据它们自动改变闭环PI增益。
- 原过流标志只清除V/f调制度、不能停止FOC；现在故障会停止FOC/标定并在当周期输出中性占空比。持续过流门槛约20A（连续5个PWM采样，非硬件瞬时峰值保证）。
- `HostUI/crowerfoc_gui.py`：新增换相诊断参数；`tools/commutation_probe.py`：串口验证及原始记录。原固件/GUI各保存了一份 `.before_commutation_fix` 备份。

SSC规范参照 [Infineon TLE5012B datasheet，§4.4.1](https://www.infineon.com/assets/row/public/documents/24/49/infineon-tle5012b-exxxx-datasheet-en.pdf)。

## 仍未解决/验证的事项

1. 参数Flash持久化仍未实现；重启或重烧后需重新标定。不要把“保存”按钮视为有效持久化。完整标定约27秒，自动测量时会实际转动约一圈机械角（取决于测得pp）。
2. 本次R读数仍约1.167Ω，L约182.5μH；R明显包含逆变器非理想因素，尚未准确分离死区/器件压降。你提供的200mΩ是两相间电阻；若是星形绕组，每相约100mΩ，接法未确认时不能直接换算写入。
3. 捕获过单帧C相−7.39A，而A/B合计约−0.10A，三相和不一致；C相采样/共模瞬态问题仍需单独排查。当前Clarke使用A/B，未把C相异常数据隐藏或替换。脚本超过3A连续两帧、单帧超过10A、速度超过8rad/s或固件故障会停止。一次速度上限触发已验证脚本停止行为。
4. 没有完成ADC尖峰源、死区补偿、R/L精密测量、编码器高速预测、满载稳定性、位置/速度环整定、UART/CAN或Flash保存。
