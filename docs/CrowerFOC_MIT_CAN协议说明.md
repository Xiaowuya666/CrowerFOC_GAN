# CrowerFOC MIT 布局 CAN 协议说明

## 当前实现

- CAN Classic，标准 11-bit ID，默认 1 Mbps、节点 ID=1；FDCAN1 使用 PB13/TX、PB12/RX。设备接收命令 ID `node_id`；收到该节点首个有效 8 字节帧后，以同一 ID 周期回传状态，周期约 1 ms。没有主控时固件不会持续发送空闲帧。
- 控制帧借用常见 MIT 运控的 8 字节位布局：`p[15:0] | v[11:0] | kp[11:0] | kd[11:0] | Iq_ff[11:0]`。本项目所有控制量和反馈量都使用电流，不定义扭矩、Nm 或电流到扭矩的换算。
- 字段范围：位置 ±12.5 rad，速度 ±30 rad/s，Kp 0..500 A/rad，Kd 0..5 A/(rad/s)，Iq 前馈 ±40 A。控制律为 `Iq_cmd = Kp*(p_ref-p) + Kd*(v_ref-v) + Iq_ff`，约 1 kHz 更新，最终请求受运行电流限制裁剪。
- MIT 来源仅用于帧的位布局；本项目自定义了其单位语义和反馈格式，因此这不是采用标准 MIT 扭矩语义的即插即用设备。控制位置不使用固定减速比。未启用输出轴编码器时，反馈使用电机轴编码器；启用并验证输出编码器后使用输出轴角度和速度。

## 控制帧

| 字节 | 字段 |
|---|---|
| 0..1 | p，16-bit unsigned |
| 2 | v[11:4] |
| 3 | v[3:0] 与 kp[11:8] |
| 4 | kp[7:0] |
| 5 | kd[11:4] |
| 6 | kd[3:0] 与 Iq_ff[11:8] |
| 7 | Iq_ff[7:0] |

量化公式为 `uint = round((x-min)*(2^bits-1)/(max-min))`；主机客户端将越界值饱和到协议边界。位置字段范围为 ±12.5 rad；连续旋转时主控应按反馈处理回绕，并持续更新位置目标。

## 特殊命令

CAN ID 为 `node_id`，数据前 7 字节为 `FF`，末字节操作码：`FC` 仅在 IDLE 时请求使能，`FD` 退出并回到 IDLE、`FE` 在 IDLE 时设置本次运行的零点。使能要求 CAN 已获 USB 许可、已标定、无故障且调制输出关闭；CAN 不能用 `FC` 抢占 USB 正在控制的轴。取得许可后首个有效运控帧可自动进入闭环。停止或故障会撤销 CAN 许可；故障后需要经 USB 清故障，再显式重新许可。CAN 控制帧超过 100 ms 未刷新时，通信看门狗停止驱动并锁存故障。

## 状态回传

CAN ID 为 `node_id`，每帧 DLC=8：byte0 节点 ID；byte1..2 位置 16 位；byte3..4 速度 12 位；byte4 低半字节与 byte5 组成实测 Iq 12 位；byte6 温度偏移值（摄氏温度+40，`FF` 表示无传感器）；byte7 为故障状态（0 正常、非 0 有故障）。位置、速度和电流字段使用与控制帧相同的范围。

## 第二编码器与输出轴测量

第二只 TLE5012B 与电机编码器共用 SPI3_SCK / SPI3_DATA，独立片选为 PB6 (`SPI3_CS_ENC2`)。主板网表中 FPC1-2 接该片选、FPC1-3 接 DATA、FPC1-4 接 SCK、FPC1-1 接 VDD、FPC1-5/6/7 接地。固件每约1ms读取两只编码器；对各自角度展开后计算输出轴多圈角度和速度，并用两轴累计转角的比值在线估算传动比，不采用写死减速比。输出编码器未启用或读数异常时，速度/位置控制不允许启动。

## 验证状态与限制

已完成的验证：

- Python MIT 编解码单元测试通过，覆盖 8 字节字段、±40 A 编码边界、反馈温度/故障字段及特殊命令。主机和固件对量化中点统一使用半值向上取整。
- 固件辅助逻辑回归覆盖看门狗边界/32-bit 计数回绕，以及 `FC` 在许可、故障、标定、轴状态和调制输出各条件下的使能门控。
- PCAN-USB 在 1 Mbps 下完成真实总线收发。CN3 的 CANH/CANL/GND 线序已核对；板端补装 120 Ω 后，总线断电测得约 60 Ω。发送错误节点 ID 的帧不会触发本节点控制；正确节点帧可触发状态回传，CAN 接收/发送计数均有增长。
- 运行电流限值临时降至 1 A，分别发送 +0.2 A、−0.2 A 和归零命令。USB 遥测测得 Iq 中位数约 +0.202 A、−0.195 A、+0.021 A；无故障，完成后返回 IDLE 并恢复 40 A 配置。另验证 `FC` 使能、`FD` 禁用及 `FE` 空闲置零。
- 编码器换相标定源码包含极对数/方向估算、静态偏置、正反向扫描及相位一致性判据；这证明判据路径存在，不能替代对实际机械角、相序和带负载换相的验收。第二编码器当前未连接，输出轴角度、方向、速度和减速比均未验收。

仍未完成的验收：CAN 命令超时停机与重新许可的实机断帧测试、总线 bus-off 后恢复、不同波特率/节点冲突、第三方主控互操作性、负载下长时间运行，以及 ±40 A 的电流能力。高电流和持续电流能力未认证；不应通过越过现有限流来宣称通过。CAN 看门狗边界及控制器门控现有软件回归，但需在限流不高于 1 A 的条件下单独做实机断帧与重新许可验证。编码器 1 的公式与标定判据已实现，但历史上的换相异常不能仅凭代码或 MIT 测试宣称已解决，需重新完成实际旋转校验。电流环扫频有效点/带宽状态见快速使用指南和扫频记录。

MIT 位布局与特殊帧格式参照 [T-Motor AK 系列模组驱动说明](https://store.tmotor.com/images/file/20220307/1646621088818055.pdf) 第 35–38 页；此处仅参考字段打包方式，CrowerFOC 的字段语义为电流。
