# CrowerFOC 关节轴核心实现与验收状态

更新时间：2026-10-09（上海）。本文更新并覆盖 [旧版 ODrive 差距快照](ODRIVE_FEATURE_GAP_20261009.md) 中过期的“位置、Flash、CAN 等未实现”状态；旧文的型号差异仍可参考。

## 当前工作树能力

- 三相 PMSM FOC：40 kHz 电流环、三相采样、Id/Iq PI 向量限幅与抗饱和。最新工作树改为带 ADC 静默窗口限制的居中 SVPWM；电机板是否已运行此修改，取决于当前 DAP 烧录结果。
- TLE5012B SSC 角度及电角度换相、角度观察器、采样延迟补偿；机械位置连续累积于 RAM。未验证极限速度、掉电多圈参考和高转速相位裕量。
- 电流、速度和位置三级控制；速度斜坡、电流斜坡、二阶位置滤波、梯形轨迹、环形位置、可选软件限位和速度/惯量前馈路径。Nm 输入和电压模型前馈需可信 Kt；默认使用 Iq[A]。
- 运行限流默认40A；校准独立使用固定5A。实机校准在5A下约14.5s，测得pp=21、dir=+1、相R≈97.7mΩ（折算线间约195.3mΩ）、L≈147.7µH。R/L仍有逆变器压降和测试误差，数值由设备实测，不写死电机参数。
- Flash 配置双页保存、版本号、CRC、提交标志、参数范围校验和启动恢复。已在板上保存两次、软件复位并确认恢复标定参数。突然断电中途恢复尚未做物理断电注入测试。
- CAN Classic 收发、GM6020报文ID/字段分组；指令自定义为±30000映射±40A，再由运行限流裁剪，默认节点1/1Mbps。此映射不是GM6020原生电压语义。当前没有物理CAN适配器，不能宣称总线实机验收通过。
- 母线欠压/过压、估算母线功率/回充抑制、主机心跳、MCU IWDG、参数事务、状态与浮点诊断、Flash保存/恢复均已接入。回充限制只是估算软约束，不替代硬件制动电阻或可吸收电源。
- 板载温度和绕组温度保护代码保留；板载NTC尚未焊接、绕组传感器未接线，两项默认关闭，当前无法提供真实热保护。
- 上位机外显速度统一rpm、位置统一°、电流A；旧USB线协议内部仍采用SI值，由主机层转换。支持配置备份/事务恢复、校准进度和结果、状态禁用/停止、诊断曲线。Python USB客户端见 `HostUI/crowerfoc_client.py`。
- 当前传动比为电机轴到关节输出 9:1；速度/位置命令和常规遥测均按输出端显示，电机转子角、电角度仍按电机侧诊断。关节连续旋转额定机械上限暂按用户给定的230rpm，电机侧对应2070rpm；过速保护可设至235rpm输出。只读参数0x0416报告9:1。该传动比是当前硬件常量，换减速箱需修改固件常量并重烧。

## 转速与电压上限

此前“速度上限约95.5rpm、跳闸约76.4rpm”是旧直驱坐标下10/8rad/s默认值，并非电机能力限制；而且跳闸阈值低于命令上限，会在命令达到上限前保护停机。当前源码将用户给定的减速比9:1纳入换算，命令限制230rpm关节输出、跳闸235rpm关节输出（电机侧分别2070/2115rpm）。旧直驱工厂值和旧版保存的230/235rpm满量程配对会精确迁移，不覆盖校准或其它用户设置。另发现旧默认轨迹速度参数0x0310=94.24778rad/s，按关节端恰为100rpm；位置梯形轨迹在此模式下会被100rpm硬限速。当前源码已把该精确旧默认迁移至230rpm上限。此处最新改动已构建并测试，但尚未重新烧录；板上先前确认的230/235rpm速度/跳闸参数仍有效，旧100rpm轨迹限值尚待设备安全空闲后更新。

编码器主循环目标采样周期为500µs，即2kHz，按单圈机械角采样的Nyquist条件理论边界约60000rpm；SSC事务、滤波延迟、转子相位误差和电机本身的电压/机械限制会显著降低可用上限，所以Nyquist数字不等于可运行额定值。

固件调制器采用SVPWM零序注入并保留ADC静默采样窗口，占空比约限制在26.7%–73.3%；在24.46V母线下径向电压限幅约6.52V。2026-10-09低电流分档试验显示，100rpm关节输出可跟随，从150rpm请求起速度停在约105rpm且Vq饱和于6.5V，确认采样保护窗口导致当前调制电压受限。详见[速度上限诊断](SPEED_LIMIT_DIAGNOSIS_20261009.md)及配套曲线。此固件安全保留采样窗口，未为提速而缩窄保护带。

## 弱磁判断

现有实机记录仅到±30rpm，q轴电压约0.5V，远低于SVPWM限幅；没有证据证明电机已进入基速以上。也没有可信Kt/反电势常数或铭牌基速，因此不应自动注入负Id。

弱磁只在高速下反电势/电感压降使电压矢量持续接近上限时才有意义；它会用负d轴电流抵消永磁磁链，降低可用q轴转矩余量并增加铜损和温升。先以限流分档升速，记录rpm、Id/Iq、Vd/Vq、电压利用率、故障和温度；确认持续饱和后，再做受限Id斜坡实验。温度传感器未接通前不能进行高负载弱磁验收。

## 实机回归与限制

`tools/axis_feature_results/20261009_174134_features.json`记录了USB参数校验、保存/复位恢复、±30rpm、20°梯形轨迹、心跳停机和ISR耗时；这些测试发生在确认9:1减速比之前，历史位置/速度日志是旧坐标，不能作为关节输出验收。此轮位置回归 `20261009_174759_control.json` 在+20°方向误差0.87°，反方向误差3.12°，超过2°验收线而失败。当前COM7仍拒绝打开，DAPLink亦未枚举为调试探针，设备状态未知。

最近一次可读取设备时的USB回读：空闲、无故障、Iq=0A、母线约24.46V、电流上限40A、pp=21、标定质量约0.999、速度限值230rpm、跳闸235rpm、传动比9:1。速度参数已保存（Flash序号4），经DAP硬复位后再次读回一致。本次受控低电流速度扫描已确认所报约100rpm现象来自当前SVPWM电压限幅，而非速度单位或软件指令上限。旧默认轨迹速度迁移仍只在工作区源码中，尚未烧录；它不影响本次速度直通模式结果。40A峰值、20A持续、热、再生、CAN实物、超速和弱磁仍未验收。
